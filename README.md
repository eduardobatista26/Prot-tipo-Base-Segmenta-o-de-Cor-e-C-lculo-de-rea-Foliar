# Prot-tipo-Base-Segmenta-o-de-Cor-e-C-lculo-de-rea-Foliar
Este código realiza a conversão da imagem para o espaço de cor HSV (Hue, Saturation, Value), isola os pixels que correspondem à tonalidade verde da planta e calcula uma estimativa da área foliar em centímetros quadrados com base em um fator de conversão espacial.
